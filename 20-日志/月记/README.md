# 🗓️ 月记

> 每月一篇，记录本月发生了什么、完成了什么、下月计划。

## 概念

命名 `YYYY-MM.md`，用 `monthly-review-template` 创建。月记记录事实和计划；对自己的深度反思写在 [[03-领域/读书写作/自省/每月自省/README|每月自省]]，月记里可以链接过去。

## 使用规范

- 放这里：月度记录（`type: "Monthly Log"`）
- 数据来源：本月各篇 [[20-日志/周记/README|周记]]、项目进度、HOME 本周聚焦
- 财务月报 → `03-领域/财务规划/`
