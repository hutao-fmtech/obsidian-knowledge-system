# 📑 书摘笔记

> 整本书的原文摘录与结构整理。

## 概念

以原书为中心：章节结构、关键原文、术语定义，方便回查。例如《人月神话》《系统思维》。和 [[03-领域/读书写作/读书笔记/README|读书笔记]] 的区别：书摘记"书里怎么说"，读书笔记记"我怎么想"。

## 使用规范

- 放这里：书的摘录和结构整理（`type: "Book Excerpt"`），命名 `《书名》- 作者.md`
- 加入了大量个人思考、改写成自己的理解 → 转为 `Reading Note`，放到读书笔记
