# 📰 文章收藏

> 读过、值得留存的外部文章和帖子笔记。

## 概念

一篇文章或帖子一份笔记，保留原文要点和出处，可以附一段个人批注。AI agent 或剪藏工具入库的文章笔记在 [[01-收件箱/01-收件箱-README|收件箱]] 分诊后，保留价值的移到这里。

## 使用规范

- 放这里：外部文章、X 帖子、公众号文章的阅读笔记（`type: "Article Note"`）
- 不放这里：整本书的笔记 → [[03-领域/读书写作/README|读书写作]]；只存链接没读过 → [[04-资源/链接收藏/README|链接收藏]]
- 文章里能独立复用的结论，用自己的话提炼到 `10-卡片盒/`，并链接回这里
