# 04-资源 - 外部参考资料库

本目录存放**外部来源的参考材料**，是知识流转链路的起点：`04-资源/` → 消化理解 → `10-卡片盒/` → 创作输出 → `30-输出/`。

## 分类框架：按使用意图

| 一级目录 | 意图 | 判断问题 |
|----------|------|---------|
| `参考资料/` | 查 | 需要时翻阅，不需要从头读完 |
| `学习材料/` | 学 | 线性消化，有完整的学习路径 |
| `工具箱/` | 用 | 操作性内容，边做边查 |
| `媒体资源/` | 学 | 影视、播客（学习材料的媒介形式） |
| `链接收藏/` | 待定 | 还未消化的外部链接，处理后归入上三类 |

**判断口诀**：拿到一个资源，问"我拿它来做什么"——查 → `参考资料/`，学 → `学习材料/`，用 → `工具箱/`。

## 放置决策

**放 `参考资料/`**：技术文档、数据手册、调研报告、方法论框架
**放 `学习材料/`**：书摘笔记、文章阅读笔记、在线课程笔记、论文笔记
**放 `工具箱/`**：工具使用指南、配置记录、资源导航链接

**不放这里，放其他地方**：
- 书籍/专栏阅读笔记（深度） → `03-领域/读书写作/读书笔记/` 或 `专栏笔记/`
- 从资源提炼出的个人洞察 → `10-卡片盒/`
- 对外发布的成品 → `30-输出/`

**AI 生成内容**：归入对应意图的目录（调研报告 → `参考资料/调研报告/`），不单独建目录。

## 操作规范

**新增资源时**：
1. 判断归属子目录（参考资料 / 工具 / 媒体库）
2. 放入 `参考资料/` 时选择对应主题子目录，主题不存在则新建
3. 保存前先搜索，避免重复保存同一资料

## Frontmatter 规范

`type` 取所在槽位 README 的 `slot.accepts`（如 `Reference` / `Tool Note` / `Article Note`），不要写中文或路径。完整字段见 `00-系统/Frontmatter 规范.md`。

## AI 生成内容的特殊处理

- **注明来源**：frontmatter 中填写 `generated.by`（旧字段 `ai_source` 不再使用）
- **时效性**：AI 技术类内容有效期约 3-6 个月，每半年核验一次
- **可验证性**：核心观点应追溯原始出处，不以 AI 摘要为最终依据
- **提炼到卡片盒时**：必须用自己的话重写，不能直接搬运 AI 输出

## 与其他目录的关系

- **下游 `10-卡片盒/`**：资源消化后提炼的个人洞察放卡片盒，见 `10-卡片盒/AGENTS.md`
- **上游 `01-收件箱/`**：临时捕获先放收件箱，整理后归入对应主题子目录
- **平级 `03-领域/读书写作/`**：书籍/专栏笔记在那里，不在这里
