# 🔧 工具箱

> 用过、在用的工具，以及它们的使用经验。

## 概念

一个工具一份笔记，记录用途、配置和踩过的坑。按形态分：`软件工具/`（本地软件，再分开发、效率、创作）、`在线服务/`（SaaS、云服务）、`资源导航/`（常用站点入口）、`模板素材/`（创作用的模板和素材）。

## 使用规范

- 放这里：工具使用笔记（`type: "Tool Note"`），命名 `工具名 使用笔记.md`
- 用工具做事的通用方法（如"如何设计 Skill"）→ `10-卡片盒/方法卡片/`
