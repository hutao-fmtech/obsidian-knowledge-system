# 🧭 资源导航

> 长期使用的站点入口：学习网站、技术社区、资源聚合。

## 概念

和 [[04-资源/链接收藏/README|链接收藏]] 的区别：链接收藏是"以后可能看"的单个链接；资源导航是"经常回来用"的站点，按主题汇总成一页。

## 使用规范

- 放这里：按主题整理的站点清单（`type: "Bookmark"`），每个站点附一句用途
- 某个站点用得深、需要记录用法 → 单独写 `Tool Note` 放在 `在线服务/`
