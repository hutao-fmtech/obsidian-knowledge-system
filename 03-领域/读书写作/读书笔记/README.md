# 📖 读书笔记

> 读完一本书，用自己的话写下理解和思考。

## 概念

整本书的阅读笔记，重点是"我读懂了什么、和我有什么关系"，不是原文摘抄。例如《Team Topologies》《竞争战略》的笔记。

## 使用规范

- 放这里：整本书的笔记（`type: "Reading Note"`），用 `reading-note-template` 创建，阅读进度写 `reading_status`
- 只摘录原文、整理全书结构 → [[04-资源/学习材料/书摘笔记/README|书摘笔记]]
- 单篇文章 → [[04-资源/学习材料/文章收藏/README|文章收藏]]
- 书中能独立复用的结论，提炼到 `10-卡片盒/` 并链接回来
