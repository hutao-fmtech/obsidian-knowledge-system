# 📚 读书写作领域总览

## 📖 领域定义

**这个领域是什么？**

读书写作领域涵盖我的日常阅读、思考沉淀和个人写作。这里记录的是**内部积累**——读书笔记、专栏学习、个人观点和自省复盘，不一定对外发布。

**为什么重要？**

- 阅读是获取外部知识和视角的主要途径
- 写作是深化思考、检验理解的最好方式
- 持续输入输出形成正向循环，防止知识停留在表面
- 自省和复盘让经历转化为成长

**与 `30-输出/` 的边界**：

| 放这里（03-领域/读书写作） | 放输出目录（30-输出） |
|--------------------------|----------------------|
| 读书过程笔记、摘录、感想 | 加工后对外发布的书评 |
| 专栏学习笔记（供自己查阅）| 博客文章、公众号文章 |
| 个人日常思考、观点草稿 | 打磨完成的技术/思考文章 |
| 自省、周复盘、月复盘 | 演讲稿、公开分享材料 |

## 📅 日常习惯

### 每日习惯

- [ ] 阅读书籍或专栏 30 分钟
- [ ] 遇到好观点立即记录到思考写作或收件箱

### 每周习惯

- [ ] 完成一次周复盘（`自省/每周复盘/`）
- [ ] 整理本周摘录，沉淀 1-2 个好想法
- [ ] 推进当前在读书籍

### 每月习惯

- [ ] 月度自省（`自省/每月自省/`）
- [ ] 完成 2 本书的阅读
- [ ] 将本月思考中最有价值的 1-2 个想法写成卡片盒笔记
