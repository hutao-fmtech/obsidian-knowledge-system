# 🔍 每周复盘

> 对这一周的自己做深度反思：为什么这样做、想法哪里变了、要改变什么。

## 概念

和 [[20-日志/周记/README|周记]] 的区别：周记记"发生了什么"（事实与计划），每周整理时写成；每周复盘记"我怎么看、要怎么改"，由自己写，可以引用周记里的事实。

## 使用规范

- 放这里：周度自我反思（`type: "Area Note"`，用 `reflection-template`），命名 `YYYY-Wxx.md`
- 本周事件、完成事项、下周计划 → 周记
- 反思中提炼出可复用的判断 → `10-卡片盒/观点卡片/`
