# 🪞 每月自省

> 对这一个月的自己做深度反思：状态、选择、成长与偏差。

## 概念

和 [[20-日志/月记/README|月记]] 的区别：月记记录本月事实、成果和计划；每月自省剖析背后的原因和自己的变化，可以引用月记。

## 使用规范

- 放这里：月度自我反思（`type: "Area Note"`，用 `reflection-template`），命名 `YYYY-MM.md`
- 本月事件与计划 → 月记
- 跨月的长期剖析（如"三框架交叉自我剖析"）→ 直接放在 `自省/` 下
