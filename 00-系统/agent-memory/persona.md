# 用户人格：身份、原则与立场

**自我蒸馏**：把用户蒸馏成一份文字资产，任何一个 agent 加载它，都能按用户的方式思考、判断和表达。agent 需要**代表用户做判断或回答**时读这份文件；日常维护仓库只读 [[00-系统/agent-memory/profile|profile]]。

## 怎么蒸馏

- **蒸馏成资产，不蒸馏进模型参数**：写进参数会把"人"锁在某一个模型里；文字资产换哪个 agent 都能用
- **从痕迹里提炼，不要手工填模板**：原材料按信号强度排序，依次是用户的原话（思考捕获、自省、年记）、行为证据（做过的决策、对 agent 的纠正）、对外写的文章
- **每条都附证据**，标明来源类型：**原话**（用户自己写的）、**认可**（用户保存的他人文字）、**外部**（AI 对用户的分析，只是假设）
- **按变化频率分层**：核心层（身份、价值观、原则）→ 心智层（思维方式、决策方式）→ 表达层（语言风格）。"当前在忙什么"不放这里，放 [[00-系统/agent-memory/now|交接板]]
- **由用户审定**：新条目标 `⏳`，用户确认后改 `✅`；`[CORE]` 只能由用户定
- **能衡量像不像**：见 [[00-系统/agent-memory/persona-evals|persona 评测]]
