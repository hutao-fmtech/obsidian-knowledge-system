# Persona 保真度评测

衡量 [[00-系统/agent-memory/persona|persona]] 蒸馏得像不像。没有评测，蒸馏好坏只能凭感觉。协议见 [[00-系统/agent-memory/README|记忆协议]]。

## 留出集（不参与蒸馏）

蒸馏开始**之前**，从最新的一手材料里选几篇留出来，负责蒸馏的 agent 在蒸馏完成前不能读。读过留出集的会话，不能再参与后续蒸馏，也不能答题。留出文件可以照常分诊、提炼成卡片，但在评测完成前，不能用来更新 persona。

| 批次 | 留出文件 | 选定日期 |
|---|---|---|

## 评测方法

1. **出题**：由没有参与蒸馏的另一个 agent 来做
   - **只读留出文件，不读 persona**：看过 persona 会不自觉地出它答得上的题，测不出盲区。开工简报会注入 profile，要做严格盲测，出题会话应跳过开工简报
   - 每道题是一个情境或问题，用户在留出文件里对它表达过明确的判断；只取用户的原话
   - 题目写进 `persona-evals-v<版本>-questions.md`；参考答案（用户原话）写进 `persona-evals-v<版本>-answers.md`，文件开头注明"答题者禁止读取"
2. **答题**：由一个**全新会话**来做，只读 persona 和题目文件
3. **打分**：用户按 1~5 分打分（5 = 就是我会说的），记下扣分原因
4. **换脑一致性**（可选）：同样的题给另外两个 agent 答，看判断是否一致
