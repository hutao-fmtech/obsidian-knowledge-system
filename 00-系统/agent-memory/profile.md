# 用户画像

用户的偏好、原则和工作方式。只记 `AGENTS.md` 里没有的。协议见 [[00-系统/agent-memory/README|记忆协议]]。

- **确认状态**：`✅` 已经用户确认；`⏳` 是 agent 观察所得，尚未确认
- **优先级**：`[CORE]` 绝不妥协，只能由用户亲口确立或修改；`[PRINCIPLE]` 强烈倾向遵守；`[PREFERENCE]` 一般偏好，可以权衡。条目冲突时按 CORE > PRINCIPLE > PREFERENCE 处理

每条的写法：`- **[级别] 一句话结论** ✅/⏳：说明（来源：会话记录链接或用户原话，日期）`

代表用户做判断时，另读 [[00-系统/agent-memory/persona|persona]]。
